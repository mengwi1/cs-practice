# Git

## Рабочая папка, индекс и коммит

Рабочая папка — это файлы проекта, с которыми я непосредственно работаю и которые могу изменять.

Индекс (staging area) — это область, куда с помощью `git add` помещаются изменения, подготовленные для следующего коммита.

Коммит — это сохранённая версия подготовленных изменений в истории Git.

# Git

## Рабочая папка, индекс и коммит

Рабочая папка  — это файлы проекта, с которыми я непосредственно работаю и которые могу изменять.

Индекс (staging area) — это область, куда с помощью `git add` помещаются изменения, подготовленные для следующего коммита.

Коммит — это сохранённая версия подготовленных изменений в истории Git.

## Git и GitHub

Git — это система контроля версий, которая хранит историю изменений проекта на локальном компьютере.

GitHub — это онлайн-платформа для хранения Git-репозиториев и совместной работы с ними.

## git diff и git diff --staged

`git diff` показывает изменения между рабочей папкой и индексом.

`git diff --staged` показывает изменения, которые уже добавлены в индекс и будут включены в следующий коммит.
